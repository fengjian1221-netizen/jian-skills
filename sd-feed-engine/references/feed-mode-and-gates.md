# 投喂输出模式与六道闸门（Feed Mode & Gates）

> **本文档是交付层核心规则库 · 权威文件**
> 融合来源：script-writing-studio 06-core-format 第六节（A/B/C 输出模式 + 输出前六道闸门）
> 定位：分镜稿 → 可投喂提示词的**最后一关**。

---

## 〇、定位与边界

**解决什么问题**：有【视频 X】标准格式规范，但缺**"投喂前的质量控制流程"**——写完提示词直接发，容易出现：字数超限、台词念不完、写了模型执行不了的交接话术、引用图超过平台上限、图号混用。

**本文件提供**：A/B/C 输出模式选择 + 输出前**六道闸门**逐项校验。

**边界**：本文件不重定义【视频 X】字段写法（那是总控 `short-drama-director/references/model-adapters.md` 的权威）；本文件只负责**"输出模式怎么选"**与**"发出去之前必须过哪几道关"**。

---

## 一、标准化交付模式（【视频 X】唯一工业标准）

在 V7.5.0 升级中，交付模式彻底统一为**【视频 X】标准交付格式**。已彻底废除旧版七段式与 500 字假技术参数，以极简场景描述 + 角色道具映射 + 纯物理画面镜行交付：

```markdown
【视频 X】
场景描述：[完整详细的环境描述，包含时间、地点、空间布局、光线、天气、道具细节、整体氛围]
角色：本片段中实际出现的所有角色（写角色名与资产图号，多个用逗号隔开）
道具：本片段中实际出现的道具（写道具名与图号，没有则不写）
风格要求：留空，自定义输入（或 ≤30 字极简自然语言描述；严禁堆砌假技术参数）
【x-x 秒】：景别、拍摄方式、大师级运镜、画面内容、角色动作、表情、情绪、台词 / 内心独白、视觉特效、环境音效、动作音效等
```

- **Seedance 2.5 交付标准**：单段严格 **30 秒**，单段弹性分配 **10~12 个镜头**（根据节奏、信息密度与张力弹性调整，严禁每段固定相同镜数）。
- **Seedance 2.0 交付标准**：单段严格 **15 秒**，单段弹性分配 **5~6 个镜头**。
- **高燃打戏支持**：全面支持 **0.3s~0.8s 亚秒冲击帧** 与高级运镜（希区柯克变焦、360°子弹时间、滚轴翻转、贴地疾冲、移焦、升降格变速等）。

## 二、★ 输出前六道闸门（核心）

每个投喂单元输出前**必须先过六道闸门**：

### 闸门 1 · 节奏与呼吸感闸门

**目的**：确保镜头时长有呼吸感，杜绝机械等长切片，严格吃满模型时序。

```
检查项：
① 时长与镜头数双锁：
   - Seedance 2.5：总时长严格 30 秒，镜头数 10~12 个弹性分配。
   - Seedance 2.0：总时长严格 15 秒，镜头数 5~6 个弹性分配。
② 镜头呼吸感检验：
   - 严禁连续出现 3 个以上相同秒数的镜头（禁止机械 3s+3s+3s）。
   - 必须长短对冲：长镜（3.5s~5s 空间/情绪）与短镜（1.5s~2.5s 动作/对白）交错。
③ 高燃战斗亚秒冲击帧检查：
   - 允许并推荐在打斗交击瞬间使用 0.3s~0.5s 冲击帧、0.5s~0.8s 反应与借力帧。
④ 必须标注准确起止时间区间（如【00:00-00:03 秒】）。
```

### 闸门 2 · 台词与独白字数闸门

**目的**：防“台词念不完”与口型崩坏。

```
时长对应字数上限硬门禁：
  - 2 秒镜头：对白 ≤6 字，内心独白 ≤8 字
  - 3 秒镜头：对白 ≤9 字，内心独白 ≤12 字
  - 4 秒镜头：对白 ≤12 字，内心独白 ≤16 字

格式规范：
  ① 超长台词必须拆分为多个连续镜头，配合景别切换。
  ② 对白格式统一为：角色名说：“XXX”，统一中文引号。
  ③ 内心独白格式统一为：角色名内心独白：XXX（内心独白无口型，是画外音，嘴部无任何开口动作），强制第一人称。
  ④ 无台词/无独白的普通动作镜头控制在 3 秒以内（情绪长镜除外）。
```

### 闸门 3 · 字数与轻量化闸门（杜绝假参数）

```
检查项：
① 严禁在风格要求或正文中堆砌 UE5、PBR、骨相比例、光比区间等 500 字伪技术参数。
② 单单元提示词字数按模型分档（Seedance 2.0 ≤1900字 / 硬顶 2000字；Seedance 2.5 放宽到 ≤2600字 / 硬顶 3000字）。
③ 提示词字数全部留给纯物理动作、景别变化与高级运镜。
```

### 闸门 4 · 可投喂语义闸门

**目的**：删掉模型执行不了的交接话术。

```
❌ 必须改掉：
  "接下一大分镜 / 接下一段 / 接分镜2 / 承接上一段"
  → 改成可见动作、可见转接或段末状态

❌ 必须移到代码框外：
  "9:16 / 13-15秒 / 分辨率 / 模式 / 任务类型"
```

### 闸门 5 · 单组图片数量闸门（按模型分档 · 2026-10-12 修订）

```
按 A 锁模型取上限，**不得把 H3 的 9 张套到 Seedance 上**：

  MiniMax H3（Ref2VA）      图 ≤ 9 / 视频 ≤ 3 / 音频 ≤ 3 / 混合总数 ≤ 12
  Seedance 2.5（全能参考）   图 ≤ 30 / 视频 ≤ 10 / 音频 ≤ 10 / 总数 ≤ 50
  Seedance 2.0               图 ≤ 9（单参考图锁形象、无首尾帧；平台侧多锚点实测可挂 3~4 张）

（含人物、场景、道具、首帧、调度图、位置参考图、场景角度图等所有图片）

⚠️ 项目资产库可以超过上限，但单组代码框内不得引用超过该模型上限的图号
超过时 → 先保留当前段必需图片，把低风险参考合并、转文字约束或拆到下一组
```

> **为什么改**：原闸门写死「每组 ≤9 张」且未分模型——**9 张是 H3 Ref2VA 的上限**，被误当成全模型通用值，直接压制了 Seedance 2.5（官方支持 30 图 / 总数 50，权威见总控 `model-adapters.md` §5 与 `SKILL.md` §二）。2.5 用户本可多投图锁一致性，却被人为卡到 9 张。口径现与 `sd-storyboard-engine/references/storyboard-sheet-template.md` §参考图数量红线（Seedance ≤30 / H3 图 ≤9·总 ≤12）对齐。

### 闸门 5·补 · 分组三重门槛（★ 2026-10-17 新增 · 粉丝「森林」实测反馈并入）

> 📌 **来源**：粉丝「森林」2026-10-17 反馈——「分完让 AI 组装，3 条门槛：1. 小于 15 秒；2. 资产不能超过 9 个；3. 重复资产必须新起分组，不能合在一起，因为同个角色不同资产可能会影响或误导视频，也就是所谓的污染」。
>
> **裁定**：① 时长门槛**方向对、数值需分档**（15s 是 2.0 的上限，不是全模型值）；② 资产 9 个**不能照收**（9 是 H3 上限，2026-10-12 已专门修过「把 9 套到 2.5」——收它等于把修复推回去）；③ 资产隔离**属真空缺，已收**（原文无此规则）。故本节按「分档 + 分层」重写，不照抄原话。

**术语对齐**：粉丝说的「分组」= 本包的「投喂单元 / 段」= `## 【投喂单元 N/M · 段K】` 一个代码框。三者同义，本节统一叫「组」。

**门槛顺序固定**：**先按剧情断点切组，再逐条过三关**；任一关不过 → 拆组或换组，**不得硬塞**。

| # | 门槛 | 判据 | 不过怎么办 |
|---|---|---|---|
| **A** | **时长** | 单组 ≤ A 锁单段上限（**2.0 = 15s / 2.5 = 30s / H3 = 15s**）；下限见 §〇 ⑦（2.5 禁 16~24s 碎段区） | 按剧情断点拆，⛔ **不在句子中间切**（台词跨组 = 口型断裂） |
| **B** | **资产数** | 单组实际引用的**图号 + `@` 锚点**合计 ≤ 模型上限（**2.5 = 30 / 2.0 = 9 / H3 = 9**）；**实操建议 ≤9 更稳**——超过 9 个后每多一个都在稀释注意力 | 低风险参考**转文字约束**、合并同源素材，或拆到下一组（低风险项才可拆） |
| **C** | **资产隔离** | **同一角色的不同形态 / 不同年龄 / 不同服装版本，不得出现在同一组** | 按形态**新起一组**（编号仍保持相邻，见下） |

**门槛 C 的病根与边界（必须读懂，否则会跟「同角色多形态相邻编号」打架）**：

- **病根**：一组里同时挂「知夏-4 岁」与「知夏-成年」，模型会把两张脸**揉成一个人**——不是"两个角色"，是"一个角色长了两张脸"，比缺人更难修。粉丝原话「同个角色不同资产可能会影响或误导视频，也就是所谓的污染」，**机制成立**。
- **与「同角色多形态相邻编号」的关系（分层不冲突）**：
  - **相邻编号**（`asset-mapping-and-rules.md` §二 铁律 4）管**《素材接线单》的排序**——让模型建立"同一主体的两个形态"关联；
  - **门槛 C** 管**投喂单元的切分**——一次生成里**只能出现一个形态**。
  - ⛔ **不是二选一**：**编号照样相邻，组必须分开**。
- **正确写法**：`组1 = 4 岁知夏 + 温良 + 破屋` / `组2 = 成年知夏 + 温良 + 破屋`
  **错误写法**：`组1 = 4 岁知夏 + 成年知夏 + 温良`（同组双形态 = 污染）
- **⚠️ 别读成「同角色不能跨组」**：同一角色**连续出现在多组是正常且必须的**（组 1/2/3 全是 4 岁知夏 = 完全合规）。门槛 C 禁的只有**同一组内多形态并存**，不是"重复出现"。

**机检兜底**：`gate_check.py` 闸门 5 按 `--model` 分档（2.5→30 / 2.0→9 / h3→9，`--img-limit` 可覆盖）；门槛 C 目前**只做人工判据**（形态识别依赖资产卡命名，机检易误报），出稿自检时按组核对「本组是否出现同一角色的两个形态版本」。

### 闸门 6 · 素材编号一致性 ＋ 素材形态一致性闸门

> **前置**：本闸门以**素材形态声明**为准。形态三档 **M0 纯提示词 / M1 编号占位（默认）/ M2 已入库**，权威 = 总控 `short-drama-director/references/asset-delivery-modes.md`。

```
A · 编号一致性（原）
① 镜头轨中出现的每个 图N / 视频N / 音频N 是否已在素材锚定 / 映射表中定义？
② 角色/场景/道具/首帧/调度图/视频/音频职责是否混用？
③ 发现图号混用 → 先修正或提示用户确认，不直接交付

B · 素材形态一致性
④ 交付首行是否已声明素材形态（M0 / M1 / M2）？未声明 = 形态未定 → 不得交付
⑤ M0 稿内出现任何图号 → 形态违约（FAIL）：图号槽位与 M0 声明互斥
⑥ M1 稿内有图号但未附《素材接线单》 → 形态违约（WARN）：接线单是 M1 交付必备件
⑦ 稿内图号 ∉ 接线单图号集合 → FAIL（用户会去挂一张不存在的图）
⑧ 接线单每行是否写明"只控制什么 / 不控制什么"？缺项 → WARN
⑨ 是否出现"已与《资产图册》核对一致 / 已核验"之类断言？M0/M1 下本包看不到图 → 一律 FAIL（虚假核验）

机器化：python scripts/gate_check.py <投喂稿.md> --mode M0|M1|M2
```

## 三、增强触发规则（按需启用）

| 命中情况 | 默认处理 |
|---|---|
| 普通剧情段 / 常规连续段 | 推荐 C；不强行加入高级增强 |
| 用户明确要求完整字段、审查漏项、1-3 镜头高精度控制 | 推荐 A |
| 同场景顺延，下一段像继续拍 | 建议视频延长启动句；默认 C |
| 必须首帧 / 建议首帧 | 加入首帧参考，说明只锁第 0 秒 |
| 多人站位、轴线、遮挡、摄影机安全区高风险 | 加入调度图参考或侧别约束；复杂时推荐 B 或 C |
| 核心场景、反打、回切、复杂空间或高穿帮场景 | 加入场景角度参考，说明只锁拍摄方向和空间透视 |
| 公共空间、街道、商场、车站、学校、医院、营业餐厅等需路人真实感 | 加入人群密度，写清人数、层次、类型、移动方向和遮挡规则 |
| 同一道具已在场景/角度/首帧可见且又引用道具图，或道具会被拿起/移动/跨段延续 | 加入道具单实例锁 |
| 一镜到底、复杂运镜、动作戏、强遮挡转场、强声音叙事 | 推荐 B |
| 长对白单元（同一说话人连续 ≥3 句，或单句 ≥20 字） | 可选启用**台词气口标记**（§三·1）——把停顿位置与秒数写出来；不启用亦合规，闸门不判缺 |
**多增强叠加超字数时**：优先用 C，删除低收益后缀、压缩管理话术、合并重复约束，把字数留给镜头轨关键控制。**不得删除关键控制信息。**
**§三·1 台词气口标记（可选槽位 · 非必填）**

给长对白的停顿一个显式槽位：闸门 2 的「停顿补偿」是**算**停顿，本槽位让停顿**写出来**，让模型按气口表演，而不是一口气念完。

写法——**追加在台词行 `】` 之外**（引号内一个字都不许动）：

```
柳娘压低声音克制怒意，柳娘说：“你走吧，别回头。” 〔气口：句尾停顿约 0.8 秒〕
```

四条铁律：

1. **可选**：不写 ＝ 合规；只在长对白单元建议补，闸门**不判缺**。
2. **零改动台词**：标记写在 `】` **之外**，引号内台词文字一个字符不许变——「台词零丢失」优先于本条。
3. **禁写进引号台词内**：写进引号内会被模型直接念出来，破坏 `角色名说：“…”` 的口型与字数校验，闸门 0/闸门 2 与 `script_feed_diff.py` 都会**漏检该句**。
4. **不新设字段**：气口是镜行尾句内自然停顿描写（如“句尾沉默半秒”），不破坏【视频 X】字段结构（C7 不受影响）。只写「停顿位置 + 秒数」，**禁写「切镜/转场/接下一段」类工作流词**（会被闸门 4 与 C12 拦）。

秒数口径沿用闸门 2：逗号/顿号 ≈0.2s、句号/问号/叹号 ≈0.4s、省略号/情绪停顿 ≈0.6~1.0s、开口前后承接 ≥0.5~1.5s。
